# AM Forecast — фронтенд

Клиентская часть сервиса «Прогнозирование выручки методом скользящей средней». Одностраничное приложение (SPA) на React. Услуга — **период** (12 месяцев и 4 квартала) с полями «порядок» (`order_number`) и «количество дней» (`days_count`).

В ЛР5 данные берутся из mock-коллекции (`src/mock/periods.ts`), без обращения к бэкенду.

## Стек

- Vite 8.3.5, React 19.3.1, TypeScript 7.0.2
- React-Bootstrap 2.10.10, Bootstrap 5.3.8
- react-router-dom 7.18.5 (HashRouter)
- Oxlint

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на http://localhost:5173/.

## Страницы

Навигация — нижняя панель из четырёх пунктов: **Лента**, **Добавление**, **Плитка**, **Вход**. В ЛР5 реализованы «Лента» и «Плитка», остальные пункты панели неактивны.

### 1. Лента (`/#/feed`, `/#/feed/:id`)

Показывает один период за раз.

- Видео периода (если нет своего — `public/video/default.mp4`) и картинка (если нет своей — `public/img/default.png`).
- Название, порядок, количество дней, количество лайков.
- Описание: сворачивается и разворачивается кнопкой «больше / меньше».
- Кнопка «Дальше» (иконка) — переход к следующему периоду по кругу.
- Адрес `/feed/:id` открывает ленту на выбранном периоде (переход по клику на карточку в плитке).

### 2. Добавление (`/#/draft`)

Форма создания периода в два шага.

- Шаг 1 «Новый период»: поле «Название», блоки выбора изображения и видео (по умолчанию показываются картинка и видео по умолчанию), кнопка «Далее».
- Шаг 2 «Публикация периода»: поля «Порядок», «Количество дней», «Краткое описание», кнопка «Опубликовать».

### 3. Плитка (`/#/tiles`)

Список всех периодов карточками, по 2 в строке.

- Карточка: картинка, название, количество дней, лайки; клик открывает ленту на этом периоде.
- Фильтр: ползунок «минимум дней» (0–100) и кнопка «Найти». Фильтр применяется по кнопке и оставляет периоды с `days_count` не меньше выбранного значения.

### 4. Вход (`/#/login`)

Форма аутентификации.

- Поля «Логин» и «Пароль».
- Кнопка «Войти». После входа пользователь получает доступ к добавлению и удалению своих периодов.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `src/main.tsx` | точка входа, рендер `<App />` |
| `src/App.tsx` | HashRouter, маршруты, заголовок, нижняя панель |
| `src/types.ts` | тип `Period` |
| `src/mock/periods.ts` | mock-коллекция из 16 периодов |
| `src/pages/FeedPage.tsx` | страница «Лента» |
| `src/pages/TilesPage.tsx` | страница «Плитка» |
| `src/components/AppNavbar.tsx` | нижняя панель навигации |
| `src/components/PeriodCard.tsx` | карточка периода |
| `src/components/DaysFilter.tsx` | фильтр по количеству дней |
| `src/components/PeriodMedia.tsx` | картинка и видео, значения по умолчанию |
| `public/img`, `public/video` | изображения и видео (включая `default.png`, `default.mp4`) |

## Использованные хуки

- `useState` — состояния страниц (список периодов, текущий период, значение ползунка, применённый фильтр, раскрытое описание);
- `useEffect` — заголовок вкладки и загрузка данных из mock при монтировании, переключение периода при смене `id` в адресе;
- `useMemo` — фильтрация списка периодов по `days_count`;
- `useParams` — получение `id` из адреса `/feed/:id`.
