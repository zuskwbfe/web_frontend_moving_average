# AM Forecast — фронтенд

Веб-приложение для просмотра периодов (12 месяцев и 4 квартала), на которых строится прогноз выручки методом скользящей средней. Лабораторная работа № 5: интерфейс для гостя на React + TypeScript + React-Bootstrap. Данные берутся из mock-коллекции (`src/mock/periods.ts`), бэкенд не используется.

## Запуск

```bash
npm install
npm run dev      # режим разработки, http://localhost:5173
npm run build    # сборка в папку dist
```

## Страницы приложения

Внизу каждой страницы находится навигационная панель из четырёх пунктов: **Лента**, **Добавление**, **Плитка**, **Вход**. Доступны только «Лента» и «Плитка», остальные два пункта отключены.

### Лента (`/#/feed`)

Один период на весь экран в формате ленты.

- Видео периода. Если у периода нет видео, показывается видео по умолчанию (`public/video/default.mp4`).
- Справа от видео: поля темы «Порядок» и «Дней», иконка лайка со счётчиком и кнопка со стрелкой («Следующий» период).
- Внизу поверх видео: название и описание периода. Описание свёрнуто до двух строк, кнопка «больше» раскрывает его, «меньше» сворачивает обратно.
- Кнопка со стрелкой переключает на следующий период из mock-коллекции; после последнего открывается первый.

### Плитка (`/#/tiles`)

Список всех периодов карточками, по две в строке.

- Фильтр по количеству дней: ползунок от 0 до 100 и кнопка «Найти». Под ним показано текущее значение «Минимальное количество дней». После нажатия на «Найти» остаются периоды, у которых количество дней не меньше выбранного.
- Карточка периода: изображение (если его нет — изображение по умолчанию `public/img/default.png`), название, количество дней и количество лайков.

## Структура проекта

| Путь | Назначение |
|------|-----------|
| `src/mock/periods.ts` | mock-коллекция из 16 периодов |
| `src/types.ts` | тип `Period` |
| `src/pages/FeedPage.tsx` | страница «Лента» |
| `src/pages/TilesPage.tsx` | страница «Плитка» |
| `src/components/DaysFilter.tsx` | фильтр по количеству дней (props `value`, `onChange`, `onApply`) |
| `src/components/PeriodCard.tsx` | карточка периода в плитке |
| `src/components/PeriodMedia.tsx` | изображение и видео с подстановкой значений по умолчанию |
| `src/components/AppNavbar.tsx` | нижняя навигационная панель |
| `public/img`, `public/video` | изображения и видео, в том числе по умолчанию |

Используются хуки `useState`, `useEffect` и `useMemo`.
